# Monad Metropolis Hackathon: Full Details

As of October 9, 2026. Primary sources: Rules & Guidelines v3.0 (Sep 3, 2026), the Tracks & Bounties page, and the Resources page in the [hackathon.monad.xyz](https://hackathon.monad.xyz) dashboard (read after login), plus the public page [monad.xyz/metropolis](https://monad.xyz/metropolis).

## Summary

- Global online hackathon, 6 weeks, for building the "next generation of startups" on Monad (mainnet chain ID 143, or testnet).
- Build period: **Sep 1 to Oct 13, 2026, 23:59 ET** (= **Oct 14, 10:59 WIB**). Late submissions are not accepted. The version recorded at the deadline is the one that is judged.
- Judging: Oct 14 to 27. Announcement: **Nov 3, 2026**.
- After the hackathon: top teams receive ecosystem support and residency invitations, and project profiles can move on to DeltaV (800+ Monad startups).

## Submission requirements (Rules §4, §9)

- **Public GitHub repo:** complete source code, README with setup instructions, open source license (MIT/Apache/GPL/BSD), attribution for external libraries, **commit history covering the build period**. The repo must stay public after the hackathon.
- **Demo video ≤ 3 minutes** (YouTube/Loom/Vimeo): the product actually running (not a mockup or slides) and showing interaction with the Monad blockchain.
- **Monad integration:** contract addresses or transaction hashes, deployed on mainnet or testnet, an explanation of the purpose and *why Monad's capabilities are used*.
- **Documentation:** project description, architecture overview, tech stack, setup/deploy instructions.
- **Working prototype**, not a mockup or concept deck. The code must be runnable by a third party from the README. The problem and target users must be clearly stated.
- **Originality:** most of the work is created during the hackathon period. Pre-existing code may be used if disclosed in the README. **Use of AI coding tools must be disclosed in the README.**
- Teams of 1 to 5 people, 1 project per participant, 1 track per project, age 18+. Sanctioned countries may not participate. Sponsor employees, organizers, and judges may not win.
- A token is not required. If there is a token, wash trading or market manipulation means disqualification.
- **Non-confidential:** judges and sponsors may build or fund similar products. Do not submit private keys or secrets.

## Recommended technology and resources

- **Monad docs:** differences from Ethereum, gas & opcode pricing, precompiles (including P256), reserve balance (parallel execution), EIP-7702, x402, ERC-8004, MERA.
- **Mera** ([guide](https://docs.monad.xyz/guides/mera), [docs](https://mera.category.xyz/getting-started/)): a free library from Category Labs that derives an EVM account (a plain EOA) from a passkey via the WebAuthn **PRF** extension. No bundler, MPC, or backend needed. `createPasskeyWithPrfOutput` / `getPasskeyPrfOutput` produce a 32-byte secret. Requires HTTPS and a passkey provider that supports PRF (iCloud Keychain, 1Password, Google Password Manager). Note: on desktop Chrome, a passkey stored in the local profile triggers `PRF_UNAVAILABLE`.
- **Starter templates:** Farcaster miniapp, Next.js PWA (Privy embedded/smart wallet, 0x + Privy, thirdweb), React Native (Privy, Privy + Pimlico sponsored tx, thirdweb).
- **Protocol SDKs:** Aave v3 React kit, Morpho, Euler, Curvance, Perpl SDK, Alchemy Smart Wallets (gas sponsorship, pay gas with ERC-20), Blend, Zerion CLI, Uniswap v4 (hooks, Continuous Clearing Auctions).
- **MCP/agent skills:** Alchemy MCP (no API key), Envio HyperIndex skills, Uniswap AI Skills, Morpho Agents, Zerion Agent Skills.
- **Data/indexing:** Envio HyperIndex/HyperSync/HyperRPC, QuickNode Streams, Trust8004 (public ERC-8004 indexer), free RPC from Crouton Digital.
- **Free perks (1 voucher per team):** QuickNode Build 3 months, Tenderly Pro, Zerion API Builder 1 month, BlockVision Lite 2 months, Spectrum Nodes Business 2 months, Dwellir Developer 3 months.
